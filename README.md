# Rocco — Demo com seis respostas atualizadas

A demonstração permanece um único `index.html`: somente Home nova, chat fictício e painel PEDIDO, com fonte Inter e imagens incorporadas.

Atualizações:

1. Contato inicial / saudação
2. Espelho vertical/horizontal (suportes nas duas posições)
3. Tomada, bivolt, três temperaturas de LED e botão touch
4. Fixação com suporte, parafuso e bucha, sem cola ou fita
5. Pedido coletado, previsão fictícia de entrega em 29/10
6. Agradecimento: “Sigo à disposição. 😊💙”

Os textos das seis respostas seguem exatamente a redação enviada, com parágrafos e emojis. O pedido 5 segue “A caminho” e o pedido 6 “Concluído”.

Para atualizar o site: substitua `index.html` na raiz do repositório GitHub e confirme em Commit changes. O site é 100% demonstrativo: nenhuma mensagem é transmitida à Shopee.

A fonte Inter é obtida pelo Google Fonts quando online, sem redistribuir arquivos de fonte.
