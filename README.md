# Rocco Demo — correção para GitHub Pages

O arquivo **index.html** contém o site completo, inclusive estilos, JavaScript e imagens. É o único arquivo necessário para publicar.

## Atualização de repositório existente

1. Acesse o repositório `esdrasanjosdesign-sys/rocco-demo` > **Code**.
2. Abra o `index.html` existente, clique no lápis **Edit this file** e substitua todo o conteúdo pelo conteúdo do novo `index.html`. Se preferir, primeiro exclua o arquivo antigo e envie este em **Add file > Upload files**.
3. Faça **Commit changes** na branch `main`.
4. Mantenha **Settings > Pages > Deploy from a branch > main > /(root)**.
5. Recarregue `https://esdrasanjosdesign-sys.github.io/rocco-demo/` com **Ctrl+Shift+R** para ignorar o cache.

Os arquivos `styles.css`, `app.js` e a pasta `assets` de versões anteriores podem permanecer no repositório, mas este novo `index.html` não depende mais deles.

A fonte Inter é carregada através de Google Fonts enquanto há conexão com a internet. Nenhum arquivo de fonte está incluído no pacote. Todos os dados de atendimento são fictícios, e o site não se conecta à Shopee nem à API Live.
