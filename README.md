- **5 (envio):** pedido **A caminho**; coleta fictícia em **22/10/2026** e entrega prevista para **29/10/2026**. A resposta sugerida confirma os dois dados fictícios.

## Atualizar no GitHub

Substitua exclusivamente o `index.html` da raiz do repositório `esdrasanjosdesign-sys/rocco-demo` por este arquivo, faça **Commit changes** e recarregue a página publicada com `Ctrl+Shift+R` após a publicação.

O arquivo `index.html` inclui os estilos, JavaScript e imagens. A fonte **Inter** é requisitada do Google Fonts; não são distribuídos arquivos de fonte. Nenhuma ação é enviada à Shopee real.
